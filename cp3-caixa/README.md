Projeto simples de um sistema de caixa eletrônico desenvolvido em linguagem C, com foco em lógica de programação, estruturas básicas e manipulação de funções.

---

## Sobre o projeto

Este sistema simula operações básicas de um caixa eletrônico, permitindo ao usuário consultar saldo, realizar depósitos e saques diretamente pelo terminal.

O projeto foi desenvolvido como forma de prática de lógica de programação e uso de funções em C.

---

## Funcionalidades

- 💰 Consulta de saldo
- ➕ Depósito de valores
- ➖ Saque de valores
- 🚪 Saída do sistema
- ✔ Validação de entradas numéricas
- ✔ Tratamento básico de erros de entrada

---

## Conceitos aplicados

- Variáveis e tipos de dados
- Estruturas de decisão (`switch`, `if`)
- Estruturas de repetição (`do while`)
- Funções
- Passagem e retorno de valores
- Validação de entrada com `scanf`
